# Android build evidence

This directory is reserved for metadata generated by
`tools/record_android_build.py`. APK binaries are intentionally not committed
by default; the metadata must point to the build artifact used by QA.

Every build record must contain the exact Unity, SDK, NDK, and JDK versions,
SHA-256, file size, install result, device model, and test date. A build cannot
be marked available by editing `build-ladder.json` manually.
